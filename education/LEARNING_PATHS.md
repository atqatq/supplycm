# Learning Paths

This guide provides structured learning paths for different roles and skill levels.

## Path 1: Beginner (Operations Analyst)

**Goal:** Understand basic supply chain concepts and use supplycm for daily tasks.
**Estimated time:** 4 to 6 weeks

### Week 1 to 2: Fundamentals
1. Forecasting basics: simple_moving_average, single_exponential_smoothing, naive_forecast
2. Inventory fundamentals: economic_order_quantity, safety_stock_normal, reorder_point, abc_analysis

### Week 3 to 4: Intermediate
3. Accuracy measurement: mape, rmse, tracking_signal
4. Basic routing: tsp_nearest_neighbor, assignment_problem_hungarian

### Week 5 to 6: Application
5. Build a simple planning system: forecast, order, measure accuracy

## Path 2: Intermediate (Supply Chain Planner)

**Goal:** Design and optimize supply chain processes.
**Estimated time:** 8 to 12 weeks

### Month 1: Advanced Forecasting
1. Time series decomposition: classical_decomposition, holt_winters, seasonal_indices
2. Intermittent demand: crostons_method, sba_method, tsb_method

### Month 2: Inventory Optimization
3. Multi-echelon: multi_echelon_inventory, risk_pooling, square_root_law
4. Lot sizing: wagner_whitin, silver_meal, part_period_balancing

### Month 3: Network and Routing
5. Vehicle routing: vrp_savings, vrp_with_time_windows, tsp_two_opt

## Path 3: Advanced (Supply Chain Manager)

**Goal:** Strategic decision-making and system design.
**Estimated time:** 12 to 16 weeks

### Month 1: Strategy and Planning
1. S&OP: demand_supply_match, production_chase_strategy, production_level_strategy
2. Supplier management: ahp_supplier_selection, topsis, supplier_segmentation

### Month 2: Contracts and Risk
3. Contracts: revenue_sharing_contract, buyback_contract, quantity_flexibility_contract
4. Risk: monte_carlo_inventory, monte_carlo_risk, supply_chain_resilience_index

### Month 3 to 4: Quality and Lean
5. Six Sigma: x_bar_chart, process_capability_cpk, dpmo, sigma_level
6. Lean: takt_time, oee, wip_calculation

## Path 4: Specialist (Data Scientist / Operations Researcher)

**Goal:** Build custom optimization models.
**Estimated time:** Ongoing

1. Optimization: simplex_method, genetic_algorithm, simulated_annealing
2. Advanced statistics: jarque_bera_test, diebold_mariano_test, bootstrap_confidence_interval
3. Simulation: monte_carlo_inventory, monte_carlo_risk
4. Graph algorithms: ford_fulkerson_max_flow, kruskal_mst, dijkstra_shortest_path

## Certification Checklist

After Intermediate path, you should be able to:
- Forecast demand using 3+ methods
- Calculate optimal order quantities for different scenarios
- Classify inventory using ABC/XYZ analysis
- Design a basic routing plan
- Measure forecast accuracy with appropriate metrics
- Identify bullwhip effect causes
- Apply safety stock formulas correctly

After Advanced path, you should be able to:
- Run an S&OP cycle
- Design supply chain contracts
- Assess supply chain risk
- Implement quality control charts
- Apply lean principles to operations
- Optimize multi-echelon inventory
- Use simulation for decision-making
