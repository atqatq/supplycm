# Simulation in Plain English

## The Big Idea
A flight simulator for supply chain managers. Test "what if" scenarios without real-world risk.

## Key Concepts

### Monte Carlo Simulation
Run a model thousands of times with random inputs. Output = distribution of outcomes.

### Scenario Analysis
Define specific scenarios (best, worst, likely) and calculate outcomes for each.

## Memory Aid: SIM
- Set up the model
- Input random variables
- Measure outcomes
