# Scheduling in Plain English

## The Big Idea
Decide what order to do jobs. The right sequence can dramatically reduce total time.

## Key Concepts

### Johnson's Rule
For 2 machines: short M1 jobs first, short M2 jobs last. Minimizes total time.

### SPT (Shortest Processing Time)
Quickest jobs first. Minimizes average waiting time.

### EDD (Earliest Due Date)
Most urgent first. Minimizes maximum tardiness.

### Critical Path
Longest chain of dependent tasks. Determines minimum project time.

## Memory Aid: TIME
- Tardiness (EDD)
- Idle time (SPT)
- Makespan (Johnson's)
- Efficiency (NEH)
