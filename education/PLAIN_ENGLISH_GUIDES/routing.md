# Routing in Plain English

## The Big Idea
Find the best way to visit all customers. Saves time, fuel, and money.

## Key Concepts

### TSP (Traveling Salesman Problem)
Visit every city once, return to start. Shortest total distance.

### VRP (Vehicle Routing Problem)
TSP with multiple vehicles and capacity limits.

### Savings Algorithm
Start with each customer on own route, merge routes that save the most distance.

## Memory Aid: ROUTE
- Read the map (get distances)
- Order by priority
- Unite close stops (savings)
- Test the route
- Execute and monitor
