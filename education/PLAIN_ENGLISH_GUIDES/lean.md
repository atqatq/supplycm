# Lean in Plain English

## The Big Idea
Eliminate waste. Anything that does not add value should be removed.

## Key Concepts

### Takt Time
The drumbeat of demand. If customers want 240 units/day and you have 480 minutes, takt = 2 min/unit.

### OEE
Equipment effectiveness score. 100% = always running, full speed, perfect quality. World class = 85%.

### Little's Law
WIP = Throughput * Flow Time. Produce 10/hr, each takes 5hr = 50 units in progress.

### 8 Wastes (DOWNTIME)
Defects, Overproduction, Waiting, Non-utilized talent, Transportation, Inventory, Motion, Excess processing

## Memory Aid: LEAN
- Look for waste
- Eliminate it
- Always improve
- Never settle
