# Collaboration Guide

This guide explains how to participate in the supplycm community.

## Ways to Contribute

### 1. Report Bugs

Found a bug? Please open an issue:

1. Go to the Issues tab on GitHub
2. Click "New Issue"
3. Select the "Bug report" template
4. Fill in the details including:
   - What you expected to happen
   - What actually happened
   - A minimal code example that reproduces the bug
   - Your Python version and operating system

### 2. Suggest Features

Have an idea for a new algorithm or improvement?

1. Open an issue with the "Feature request" template
2. Describe the use case and proposed solution
3. Be open to discussion and feedback

### 3. Add Algorithms

Want to contribute a new algorithm?

1. Check existing issues for "good first issue" labels
2. Fork the repository
3. Create a branch: `git checkout -b add-new-algorithm`
4. Write your algorithm following the style guide in CONTRIBUTING.md
5. Add tests in `tests/test_<category>.py`
6. Run tests: `python tests/run_tests.py`
7. Open a Pull Request (PR)

### 4. Improve Documentation

Documentation improvements are always welcome:

- Fix typos
- Add examples
- Translate documentation
- Improve clarity

### 5. Review Code

Help review open Pull Requests:

1. Read the changes carefully
2. Test the code locally
3. Leave constructive feedback
4. Approve if the changes meet quality standards

## Finding Issues to Work On

### Labels

We use the following labels to categorize issues:

| Label | Description |
|-------|-------------|
| `good first issue` | Beginner-friendly, small scope |
| `help wanted` | Community help needed |
| `bug` | Something is broken |
| `enhancement` | New feature request |
| `documentation` | Documentation improvements |
| `question` | User questions |

### Quick Start for New Contributors

1. Look for issues labeled `good first issue`
2. Comment on the issue saying you would like to work on it
3. Fork the repository and create a branch
4. Make your changes following the style guide
5. Add or update tests
6. Open a Pull Request (PR) referencing the issue

## Community Guidelines

- Be respectful and welcoming to all contributors
- Provide constructive feedback in code reviews
- Help others in issue discussions
- Follow the Code of Conduct

## Getting Help

- **Issues**: Open an issue for bugs or feature requests
- **Discussions**: Use GitHub Discussions for questions
- **FAQ**: Check docs/FAQ.md before asking
